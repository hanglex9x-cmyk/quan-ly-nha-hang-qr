# Quản lý nhà hàng — Order QR

Demo quản lý nhà hàng với đặt món bằng mã QR — nhà hàng mẫu "Phố Ngon 24".

## Xem demo

Mở: https://hanglex9x-cmyk.github.io/quan-ly-nha-hang-qr/

## Nội dung

- `index.html` — trang demo tự chứa (self-contained), gồm quản lý bàn, thực đơn, đơn hàng và mã QR.

## Cách dùng

Mở liên kết demo trên trình duyệt và thao tác trực tiếp trên giao diện; không cần cài đặt hay máy chủ.
